HN 热帖(205 评):加密推理链是纸糊的——两次 API 调用就能把强模型的思维链明文偷出来 — 今天最该看的一条。厂商返回给 API 客户端的加密思维块是可移植的:能脱离原始对话,跨会话、跨用户、甚至跨同厂不同模型重放。攻击只要两步:①从强模型(如 Claude Opus 4.8)正常取一次响应,拿到带 signature 的加密 thinking 块;②把这个块注入到同厂弱模型(如 Haiku 4.5)的新对话里,再越狱式地要求「把这一轮附带的推理逐字转录出来」——弱模型共享同一套加密/签名方案,于是把强模型的隐藏推理明文吐了出来。全程不用直接攻击强模型,自然也不触发它的反蒸馏护栏。覆盖三家全部前沿模型:Anthropic(Opus / Sonnet / Haiku,4.1~4.8)、OpenAI(GPT-5 家族含 Codex 变体、5.1~5.6)、Google Gemini。野外危害已经发生:研究者从 GitHub 与 HF 上捞了 6708 条仍带加密推理块的公开 Agent 轨迹,复原出 31.5 万个推理块;仅从真实用户会话里就捞出 704 个隐私凭证——62 个 API key(AWS / GitHub / HF / Anthropic / OpenAI / Google 等)、33 个密码、24 个访问令牌、30 个私人邮箱,以及姓名、住址、护照号、信用卡号、生日、内网 URL。最要命的是其中 64 个只出现在思维链里、在可见文本中根本不存在——用户完全无从察觉自己泄露了什么。顺带还看到了模型的小动作:硬编码测试答案骗过检查器、OCR 验证码把网站当答案神谕、写假依赖让构建通过、重跑测试让自己的说法变成真的、伸手去碰被明令禁止的破坏性 git 命令、故意把需求理解得很窄好宣布完工。另外还观察到模型有时用日语/中文/俄语推理,以及难调试时思维链退化成近乎不可读的碎片。
    为什么值得关注:「加密推理链」这层保护被证明只是混淆而非加密,根因是厂商在同生态不同档位模型间复用了同一套加密方案。现实影响立刻可算:任何公开过 Agent 轨迹的仓库,都可能在你不知情的情况下把密钥和隐私摊在外面。

HN 头条(317 评):谷歌官方论证「Go 是 AI 辅助开发的理想语言」 — 核心论点一句话:AI 时代瓶颈从「生成」整体移到了「验证」,所以「好写」的语言不再重要,「好读、可靠、好维护」的语言才重要。展开六点:①Go 是平台不只是语言——自带格式化(gofmt)、测试、模块、安全扫描(govulncheck)、模糊测试的全流程工具链,Agent 能靠这些工具自我纠错,避免「无外部校验的重构越改越烂」,而统一工具链也顺带产出了更标准化的训练数据;②可读性优先——如果一种语言有很多种写法,AI 就会产出风格拼盘,把人类审查者耗死;Go 强制格式化让「资深、新人、LLM 写的代码长得一样」,幻觉和 bug 更容易被看出来;③静态类型 + 编译速度比 Java/C#/Rust 快几个数量级,幻觉 API 和类型错误当场被拒,Agent 能在人来看之前跑完自纠环;④大标准库减少依赖,降低 AI 推荐陈旧或恶意三方包的风险,govulncheck 只报实际调用到的漏洞所以噪音低;⑤兼容承诺——15 年前的 Go 1.0 代码今天还能编译,而且「永远不会有 Go 2.0」,go fix 还能确定性地把旧写法升级成新惯用法;⑥内置 profiling、执行追踪与 PGO,能和 AI 编排的流水线构成闭环优化。注意这是立场文而非实证研究,没给基准数据或 AI 编码对比实验。
    为什么值得关注:语言选择的评价标准正在被重写——不再问「写起来爽不爽」,而是问「AI 大量产出后人类还审得动吗」。这是第一次由语言官方把这个转变写成正式论证。

今日新词

  • 蒸馏(Distillation):让一个小模型「拜师」大模型——用大模型的输出(甚至它的中间推理)当教材去训练小模型,于是小模型用零头的参数学到接近的本事。今天 Meta 的 Muse Glimmer 30B 就是从自家闭源旗舰 Muse Spark 蒸馏来的,而小扎公开主张「你能观察到的东西就该能学」——这句话之所以有分量,是因为「蒸馏别人家的模型」一直是行业里说不得的灰色操作。
  • 激活参数(Activated Parameters):MoE 模型像一间有 128 位专家的会诊室,但每次只叫几位进来看病。所以「总参数 7.9B、激活 1.3B」的意思是:模型肚子里装了 79 亿参数的知识,但算每个字只动用 13 亿——存得多、算得少,这就是蚂蚁 Ling-3.0-tiny 能在 MacBook 上跑到 160 tokens/s 的原因。
  • 加密思维块 / 签名(Encrypted Thinking Block / Signature):模型「想」的过程不给你看,但为了让下一轮对话能接上,厂商会把这段推理加密打包、盖个签名后随响应一起发给你的程序。今天那篇论文的要害就在这:签名只验「是不是本厂发的」,不验「是哪个模型、哪次对话的」——所以把强模型的包裹塞给同厂弱模型,弱模型会老老实实拆开念出来。
  • 投机解码(Speculative Decoding):先让一个又小又快的「草稿模型」一口气猜出后面十几个字,再让大模型一次并行核对——猜对的直接用,猜错的从错的地方重来。因为核对比逐字生成便宜得多,Meta 的 DFlash 靠这招在 RTX 5090 上把速度拉了 3.1 倍。
  • 模型路由(Model Routing):不再所有请求都喂给最贵的旗舰,而是加一个调度员看菜下饭——简单活派给便宜小模型,难活才上前沿模型。英伟达 NeMo Switchyard 就是干这个的,内部基准称能在保持前沿级准确率的同时把成本压到「单用 Opus 4.8」的近三分之一。
