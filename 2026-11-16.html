今日术语

  • Baseline:一个描述「某个 web 特性在主流浏览器里普及到什么程度」的公共数据集。Widely Available 大致等于「所有主流浏览器都支持了 2.5 年以上」,拿它当编译目标就不用自己背兼容表。
  • Agent Skills:一种让 coding agent 按需加载领域知识和操作流程的开放格式(一个目录 + 说明文件)。跟 MCP 的分工是:MCP 负责「能调什么外部工具」,Skill 负责「该怎么用它、遵守什么规矩」。
  • CNCF Sandbox:云原生计算基金会项目成熟度的最低一档,表示「有潜力、值得中立托管」,但不等于生产就绪;往上还有 Incubating 和 Graduated。
  • SOP 工作流(在 agent 语境下):把一次交付拆成写死的步骤序列(实现 → 审查 → 人工验收 → 合入),每步指定由谁执行、卡在哪里要人点头,目的是让 agent 的产出可复现、可追责。
