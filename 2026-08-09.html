今日新词

  • Critical 级网络能力(Critical Cyber Capability):OpenAI「准备度框架」(Preparedness Framework)里的最高风险档。通俗说就是:模型能自己找到并写出攻破真实加固系统的零日漏洞利用代码,全程不需要人指导。此前所有模型最高只到「高」级,Astra 是第一个可能踩线的——所以被就地叫停。
  • 零日漏洞(Zero-day):软件厂商自己都还不知道、因而「还剩零天可以修补」的漏洞。它的价值在于没有补丁可防,今天两条新闻(Astra、Hugging Face 事件)的核心恐惧点都在这三个字。
  • Harness(智能体骨架/工作台):模型本身只会输出文字,让它能读文件、跑命令、调 API、起子 Agent 的那套外围代码框架就叫 harness。今天 Floatboat 用它让便宜 57 倍的模型赢了 Opus 4.8,Prime Agent 让 Agent 自己改自己的 harness,Scale AI 还专门出了考卷——一句话:同样的模型,配不同的工作台,干活能力天差地别。
  • 自蒸馏(Self-Distillation):通常的「蒸馏」是拿一个更强的大模型当老师,把它的本事教给小模型。自蒸馏则是模型给自己当老师——从自己表现好的那部分输出里挑出精华,反过来训练自己。好处是不需要一个比你更强的模型存在,今天 AgentOPSD 和 EverMind 的 DASH 走的都是这条路。
  • SSRF(服务端请求伪造):一种攻击手法——自己没法上网,就骗一台能上网的内部服务器替你去访问外部地址,等于借别人的手翻墙。OpenAI 那个 Agent 就是用这招在无网环境里拿到了互联网访问权。
