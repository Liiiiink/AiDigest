论文前沿

  1. 🆕 AgentOPSD:不用 critic、不用额外采样,给 Agent 的每一步单独记功 — HF Papers 今日第一(75 赞)。长程多轮 Agent 训练的老大难是功劳分配:任务成功与否是一个总分,但真正决定成败的往往只有其中几步关键决策,轨迹级的优势估计根本分不清谁该记功。AgentOPSD 的做法是把 token 级的师生对数概率差聚合成轮次级证据,再在对数几率空间里递归更新一个贝叶斯信念状态,通过相邻状态之间的边际信念修正来识别「关键轮次」,从而把稀疏的结果监督转成稠密的轮次级信号。工程上很轻——既不需要额外的 critic 网络,也不需要多跑 rollout,可直接嵌入标准策略优化。在 ALFWorld、WebShop、Search-QA 上以 Qwen2.5 的 3B / 7B 验证,超过 GRPO 与多个强自蒸馏基线,ALFWorld 上 7B 拿到 89.1% 成功率。消融实验确认收益确实来自「轮次级聚合」和「依赖历史的递归信念更新」两项设计。
    为什么值得关注:Agent RL 的成本大头是采样和 critic,而这篇把两样都省了。它和昨天的 EnvACE(省环境)是同一种思路——当训练 Agent 变贵,创新的方向就从「加什么」变成「砍什么」。
    研究arXiv2026-08-08
  2. 🆕 GST-Bench:看了 6790 分钟视频,顶尖视觉模型依然「不知道自己在哪」 — HF Papers 上榜(37 赞)。现有空间智能基准几乎都在测单视角或少数视角下的局部感知,没人系统检验模型能否在长视频里维持一个全局一致的场景表征。GST-Bench 用 6790 分钟合成视频 + 人工核验问题构建,要求模型从视频里根本没出现过的视角做空间推理,并把第一人称观察映射到全局俯视地图上;还配了 GST-Bench-Local 用于区分「局部看不懂」还是「全局拼不起来」,以及训练集 GST-Train。22 个前沿视觉模型参评,最好的零样本成绩仅 42.68 分,而人类是 79.08。结论明确:模型的局部空间理解其实不弱,瓶颈在于把长时间跨度的观察整合成一张连贯的地图。
    为什么值得关注:这是具身智能和机器人绕不开的一关——你可以逐帧看懂每个画面,却依然说不出「刚才那个房间在我左边还是右边」。人类 79 分 vs 模型 43 分的差距,划出了当前多模态模型最真实的一条边界。

  3. 🆕 从「经济人」到「智能体经济」:给经济世界模型画一张六级能力阶梯 — HF Papers 高赞(48 赞)。所谓经济世界模型(EWM),是用生成式模拟让一个经济体「从内部自己长出来」——异质的个体、他们之间的互动、以及市场与制度机制。作者提出一条六级能力阶梯:从最基础的规则驱动智能体世界,往上到自适应 / LLM 驱动的智能体、能自我进化的智能体、制度本身也会演化的世界,最终到与真实观测对齐的「模拟-现实经济孪生」。系统性文献扫描的结论很直白:现有工作几乎全部挤在低层级,而自进化智能体、内生制度、持续的经验对齐、经过验证的经济机制,统统罕见。论文附了一份 GitHub 资源清单。
    为什么值得关注:它给出的双重定位很有意思——这类模拟既是给人类决策者用的高保真沙盘,也是给 AI Agent 用的训练、规划、评测与安全底座。当越来越多 Agent 要在真实经济活动里做决定,你总得先有个地方让它们摔跤。

  4. HarnessOpt-Bench:把「优化脚手架」本身当成一项模型能力来考 — 它测的是一件以前没人系统量化过的事:前沿模型有多会优化「模型周围的那一圈东西」——提示词、工具、控制流、记忆与编排代码。玩法是:给优化者模型一个目标 Agent 的种子 harness、评测反馈和固定预算,让它反复改写、最后提名一个候选版本,按在隐藏测试集上相对种子版的归一化增益计分;全程在可信执行环境里跑,计量资源、保留所有候选版本以供审计。5 个前沿模型 × 4 个下游任务 × 111 次计分运行,得出三条结论:优化者模型之间的差距,大于它们所用编码 harness 之间的差距;用「自家原生 harness」并不总是更好;收益高度依赖任务与种子版本。
    为什么值得关注:它把 prime-agent 那种「Agent 自己改自己脚手架」的能力,钉成了一个可测量的坐标。而现有模型在这项上的分数,离天花板还很远。

今日新词

  • RSI / 递归自我改进(Recursive Self-Improvement):让 AI 参与改进 AI 自己的模型、算法、数据和研发流程。今天出现了三个不同层次的版本:prime-agent 改的是脚手架(Agent 自己重写自己的运行逻辑),EverMind 攒的是技能库,而 BigBang-V1 更激进——连训练数据都交给 AI 生产。它诱人的地方在于:不需要存在一个比你更强的老师。而它成立的前提也很硬:必须有个靠谱的验证器,否则自产自销就是自我催眠。
  • 可验证任务(Verifiable Task):答案能被机器自动核对的任务——代码能不能跑通、数学证明能不能被 Lean 检查、仿真结果对不对。这是 AI 自己给自己出题时的「防作弊底线」:题可以你出,但对错不能由你说了算。BigBang-V1 之所以选科学领域,正因为科学天然同时满足「前沿」和「可验证」两个条件。
  • 功劳分配(Credit Assignment):一个 Agent 跑了 30 步最后成功了,到底是哪一步起了决定作用?训练时如果把这 30 步一视同仁地奖励,模型就学不到重点。AgentOPSD 今天的做法是用贝叶斯信念更新去定位那几个「关键转折点」——只给真正改变了局势的那几步记大功。
  • 奖励模型 / AI 当裁判(Reward Model / LLM-as-a-Judge):训练和评测 Agent 时,需要有人判断「这次任务算不算做成了」。人判不过来,于是让另一个模型来当裁判打分。今天 OSReward 的发现是:这些裁判普遍「宽容偏差」,爱把失败判成成功——所以很多光鲜的基准分数,可能需要打个折扣看。
  • Harness(脚手架 / 外壳):模型本身只是个「大脑」,harness 是围在它外面的那一整套东西——提示词怎么写、能调哪些工具、多步任务怎么编排、上下文怎么压缩、记忆存在哪。今天 HarnessOpt-Bench 把「会不会优化 harness」当成一项能力来考,prime-agent 则让 Agent 自己动手改。可以理解成:同一位厨师,在家庭厨房和专业后厨里能做出的菜完全不是一个水平。
