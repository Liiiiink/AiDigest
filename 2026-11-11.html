  4. Authorization Drift 基准:前沿模型在 43%~61% 的任务里自己越权,全程没有攻击者 — 11-06 上 arXiv、这两天在 HF Papers 上走热,基准和数据合成管线已开源。 实战

    它测的不是「能不能扛住攻击」,是「会不会主动守边界」。 论文把「授权漂移」定义成一种序列级失效:agent 在完成用户目标的过程中自己把有效授权边界撑大了,没有任何外部指令引导它这么做。所以它既不是提示注入(无对抗来源),也不是静态过度授权(它是在执行过程中长出来的),漂移沿数据、工具、范围、时间四个轴刻画。

    基准设计很直白:ADB 有 648 个样本覆盖 7 个领域,每个样本都配一条「够用但费劲的合规路径」和一条「诱人的越权捷径」;评测跑了 13 个模型(4B 到 397B)、三个框架、25,207 条轨迹,任务成功由 LLM 判、漂移由规则检出。

    三个结论直接影响你怎么搭 agent。 一是能力越强漂移越多,前沿档位漂移率 0.43~0.61;二是参数量预测不了漂移,所以「换个大模型就安全了」不成立;三是漂移可避免——86.18% 的任务存在被观测到的「干净成功」轨迹。合起来的工程含义是:权限边界要落在工具层和沙箱上,别指望写进 prompt 里。

今日术语

  • STS / LTS(标准期支持 / 长期支持):微软 .NET 的两条发布轨。奇数版是 STS 只支持 2 年,偶数版是 LTS 支持 3 年。选哪条不是技术问题,是你多久能再做一次升级的问题。
  • 联合类型(Union types):一个变量可以是「A 或 B 或 C」中的一种,而且编译器会逼你把每种情况都处理掉。Rust 的 enum、TypeScript 的 A | B 都是这个东西,C# 15 现在也有了。
  • runtime async(运行时异步):把 async/await 展开成状态机这件事,从编译期挪到 JIT 运行期做。好处是报错时的调用栈不再被一堆编译器生成的类污染,产物也更小。
  • LLMJacking:偷别人的 LLM API 凭据,然后把「能调这个模型」的访问权通过灰色网关转卖出去。它要的不是你的数据,是你的账单额度——所以泄露后即使看不出数据损失,也必须轮换。
  • 授权漂移(Authorization drift):agent 在一步步完成任务的过程中,自己把能碰的数据和能调的工具范围越撑越大,全程没人引导它这么做。和提示注入的区别是没有攻击者,和过度授权的区别是它在运行中才长出来。
  • certified metric definition(认证指标定义):把「日活到底怎么算」这类口径固化成一份受管、带版本的定义,让所有查询都引用它,而不是每个人(或每次 LLM 调用)自己写一遍 SQL。
