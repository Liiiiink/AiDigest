动手派

今天你能用的工具、技巧、实战经验

  1. Google 开源 AX:把 Agent 当成第三类工作负载来调度 — Apache 2.0、go install github.com/google/ax/cmd/ax@latest，四个原语 Task / Workspace / Gateway / Model 全是 K8s 风格的声明式 YAML，核心论点是 Agent 既不是微服务也不是批处理——它算一会儿就卡在等外部响应上，传统编排器让沙箱空转的成本撑不住，AX 靠 checkpoint 把闲置任务挂起、亚秒级恢复。3.1k star，但 README 明确警告稳定版前会有破坏性变更。 新发布
  2. 很多快哈希函数有「万能碰撞输入」:CityHash64、FarmHash64 撞在种子生效之前 — 作者用 AI 系统扫了 SMhasher 里 40 多个变体，找出一批不需要知道密钥就能撞的输入对——CityHash64/FarmHash64 的 8 字节对碰撞分数是 0 bit(即所有密钥都撞)，komihash 在 64~127 字节区间约 91% 碰撞率，wyhash / rapidhash / XXH3 / foldhash 全踩同一个「折叠乘法忘了补码」的坑。结论别急着换 SHA——有 Lean 机器验证过 63-bit 保证的 ChainHash 和 UMASH，速度一样快。 实战
  3. Notion 公开 CRDT 落地细节:每分钟数百万操作,块模型和文本 CRDT 怎么对齐 — 原来的块级 last-write-wins 在离线模式下会直接吞掉编辑，于是基于 RGA 重做；难点不在文本而在「块」是独立数据库记录——用户按回车拆块时，一条在途操作可能指向一个当时还不存在的块。他们发明了 text instance + search label(L/R/RR 这种二进制串)把取块范围从 100 个压到少数几个，紧凑编码又把标签存储省了 5 倍。2025 年 7 月上生产。 实战
  4. jevals:用决策模型替掉 LLM-as-judge,一次请求几千分之一美分 — pip install jevals，MIT。把一条 trace 的所有 eval(工具选择、grounding、prompt 注入、PII、faithfulness)打包进一个 HTTP 请求，返回校准过的概率而不是文本，几百毫秒出结果、方差远低于前沿模型当裁判。同一套定义能直接当 guardrail 挂在请求路径上(allow / escalate / block)；后端可换本地 Qwen3 或 Apple Silicon 上 ~10ms 的 ModernBERT，也能退化成普通 chat LLM 先跑起来。 工具
  5. openmsg:让 Claude Code 和 Codex 在各自跑着的时候互相发消息 — npx openmsg list，MIT、零依赖(连 WebSocket 都是自己一个文件实现 RFC 6455)。每家 Agent 接收消息的入口都不一样，它统一抽象成 send/list/inbox/whoami，地址写成 <vendor>:<name>——Claude Code 走 session inbox socket、Codex 走 codex queue、其余回落到 hook 邮箱或 tmux send-keys。作者强调的设计底线是「没有程序去读另一个程序的屏幕」，回复也是一条新消息。 工具

值得知道但不用细读的动态

  2. Vercel 开源 json-render:让模型只能从你的组件目录里拼 UI — Apache 2.0，思路是不让模型吐 markup——你用 Zod 定义 catalog(可用组件 + 可用 action)和 registry(映射到真实实现)，模型只能产出符合 schema 的 JSON spec，再交给 <Renderer> 渲染。支持流式渐进渲染(SpecStream)、$state/$cond/$template 这类动态表达式，一份 catalog 能跨 React / Vue / Svelte / Solid / React Native，另有 shadcn 预制包。 工具
  3. Cua 推「Computer-Use 2.0」:同一个任务里在代码、API 和 GUI 之间来回切 — MIT、25.1k star。Cua Driver 能跨 macOS/Windows/Linux 操作原生应用和浏览器，且支持后台投递——Agent 干活不抢你的鼠标和焦点；配套还有按需领取云桌面的 Fleets、Apple Silicon 上跑本地 macOS/Linux 虚机的 Lume，以及能导出轨迹当训练数据的 Cua Bench。另有一组叫 CUA-S1 的小模型专做「表单该填什么」这类快速有界决策。 新发布
  4. GitHub 官方回答三个问题:Skills 没杀死 MCP,RAG 也没死 — 分工说得很清楚——MCP 给的是「标准化的工具和数据访问」，Skills 是「打包好的专业知识」(Markdown、人能读、编码团队约定)，一句话总结是「MCP 提供访问，Skills 解释怎么用好这个访问」；RAG 只是不时髦了，没有好检索模型就只能靠训练数据或烧 token 到处翻。AI 代码要不要审的答案是「审到你能解释并且敢担责为止」，深度按风险分级——生产环境的 auth 重构和一次 CSS 实验不是一个标准。 观点

今日术语

  • CRDT(无冲突复制数据类型):一种数据结构,让多人同时改同一份文档、各自离线再合并时不会丢东西——Notion 今天公开的就是它在块模型上怎么落地。
  • 通用哈希(Universal Hashing):一个「有密钥的哈希对任意两个不同输入的碰撞概率都足够低」的可证明保证——今天那批快哈希被破的正是这条,而不是加密强度。
  • Flash 档模型:各家在旗舰之下专门做的中等参数版本(约 100B~500B),为 Agent 那种高频并发调用而生,便宜快、日常编码够用。
  • LLM-as-judge:拿一个大模型去给另一个模型的输出打分——今天 jevals 想替掉的就是它,因为它贵、慢、而且同一份输入打出的分会飘。
