DeepSeek Harness 开源:「一切皆插件」,要做 Agent 时代的安卓 — 紧跟 V4 Pro 正式版,DeepSeek 把自家 Agent 脚手架 Harness 以开发者预览形式开源(github.com/deepseek-ai/deepseek-harness)。它不是新模型,而是一套构建/运行/扩展 Agent 的 SDK 与应用框架:模型无关(可接 DeepSeek 也可接其它),让模型读写文件、跑命令、管任务,并通过 Web UI / 终端 / Headless / 自动化协议与人交互。架构很硬:230+ workspace 成员、文件系统/终端/LSP/子 Agent 各自独立成包;Agent Loop 拆成严格的 Turn→Step 生命周期,工具调用走前置策略+安全守卫+执行+后置的流水线;Session Log 是唯一权威来源,支持 Resume 和 Fork;主 Agent 可委派子 Agent 并行执行。安全上默认 workspace-write 沙箱 + 失败关闭——「如果无法确认隔离真的生效,它宁可拒绝执行」。所谓「一切皆插件」是连 Agent Loop 本身都是插件,跑在 Cordis 微内核上,一份 cordis.yml 就能把同一套代码组装成终端编程助手、Web 应用、一次性任务或自动化服务。

  • TTT(Test-Time Training,测试时训练):让模型在推理(回答用户问题)的过程中同步更新自己的权重——传统模型是「训练完就固定」,TTT 模型是「边用边学」。好处是小模型可以持续进化、用大模型的能力;风险是学错了或忘了原本的——这正是 SSI 名字里「Safe」要解决的核心问题。今天 Ilya 曝光的首个模型就是基于 TTT。
