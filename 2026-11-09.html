今日术语

  • User-Agent(用户代理标识):HTTP 请求里一行自报家门的字符串,告诉服务器「我是谁」。按爬虫礼仪可以在里面留个联系邮箱——问题就出在模型留的是你的邮箱。
  • MoE 专家剪枝(Expert pruning):MoE 模型里有一堆「专家」子网络,每个 token 只用其中几个。剪枝就是直接把常年不被路由到的专家整个删掉——和量化(把每个权重存得更省)是两条路,可以叠加。
  • BPW(Bits per weight,每权重比特数):平均每个参数占多少比特。16 是不压缩,4 是常见量化档,低于 2 就属于很激进的档位了。
  • agent memory(智能体记忆):agent 跨会话留下来的、从经验里得到的知识。注意它特指写在上下文外面的东西——不包括改权重,也不包括单次会话内的上下文学习和压缩。
  • C ABI 稳定(Stable C ABI):库升级后,已经编译好的程序不用重新编译就能继续链接上去。这是一个 C 库能被别人放心当依赖的前提。
