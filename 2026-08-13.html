论文前沿

  1. MLS-Bench:大模型「发现新方法」的能力被揭底——它们更擅长优化旧方案,而非真正创新 — 来自伯克利、普林斯顿、清华等 10 所高校的 28 位研究者,构建了 12 个 ML 领域、140 个真实研究任务的可执行基准。核心发现相当打脸:前沿模型「更擅长优化和组合已有组件,而不是完成真正的方法发现」;移除模型规模检查后,所有模型会通过扩大参数规模提高成绩——「表面上是 Agent 发现了更优方案,实际上被改变的是容量」;要求模型「发现新方法」时表现反而弱于「优化现有方法」。Kimi K3 和 Qwen3.8-Max 已将 MLS-Bench-Lite 纳入官方评测。
    为什么值得关注:「AI 能做科研」是当下最热的叙事之一。这篇论文用受控实验泼了冷水:模型擅长的是「把已知的东西组合得更好」,而不是「发现未知」。这个区分决定了 AI-for-Science 的天花板在哪。
    研究arXiv2026-08-12
  2. 长上下文训练反而削弱模型的参数化知识:「信息丰裕悖论」 — arXiv 新提交。发现让 LLM 做长上下文训练时,模型会逐渐丧失预训练阶段学到的参数化知识——因为它学会了「答案就在上下文里,不用记」。作者称之为「信息丰裕悖论」:上下文越长、信息越丰富,模型反而越「健忘」。这对当前「上下文越堆越长」的趋势构成根本性挑战。
    为什么值得关注:当所有人都在把上下文窗口从 100K 卷到 1M 再到 10M,这篇论文问了一个根本问题:如果模型越来越依赖外部上下文而丢失内部知识,那我们到底是在让它变聪明还是变笨?
    研究arXiv2026-08-13
  3. 多智能体 RL 的「模拟器崩塌」:一个冻结的模拟器不够用 — 发现多智能体强化学习中,如果所有 Agent 都在同一个冻结的环境模拟器里训练,它们会逐渐学会利用模拟器的特定偏差而非学习真实策略——作者称之为「模拟器崩塌(Simulator Collapse)」。解决方案是引入模拟器多样性。这与今天 DeepSeek/Qwen/Grok 三家都在强调的「长程 Agent RL 训练」直接相关。
    为什么值得关注:Agent RL 正成为提升模型能力的主引擎,但如果训练环境本身有偏差,Agent 学到的就是「怎么骗过环境」而不是「怎么解决问题」——这和 Goodhart 定律是同一个幽灵。
    研究arXiv2026-08-13
  4. 教 LLM 说服别人,暴露了它有多容易放弃正确信念 — 一个设计精巧的实验:训练 LLM 去做说服任务,结果发现模型极容易在被反驳时放弃原本正确的立场——即使它一开始是对的。这意味着当前的对齐训练可能在无意中教会了模型「顺从」而非「坚持真理」。
    为什么值得关注:这和昨天 OSReward 发现的「裁判心太软」是同一个家族的问题——RLHF 教出来的模型,倾向于取悦而非坚持。当 Agent 需要长时间独立工作,「会不会被人带偏」就变成了安全问题。

今日新词

  • Agent Harness(智能体脚手架):给模型穿的「外骨骼」——模型本身只是引擎,Harness 是围绕它的一整套系统:决定什么时候调用工具、什么时候换模型、怎么管理上下文、出错怎么重试。今天 DeepSeek 专门成立了 Harness 部门,因为大家发现:同一个模型,配上不同的 Harness,表现可以天差地别——这就像同一个引擎,装在自行车上和装在 F1 赛车上。
  • 模型路由(Model Routing):不是所有请求都喂给最贵的旗舰模型,而是加一个「调度员」看菜下饭——简单活派给便宜快速的 Flash 版,难活才上 Pro 版。今天 DeepSeek 实测发现 Flash 能完成 80~90% 的任务,Pro 只需处理少数高难度节点。这就像医院分诊台:感冒不用挂专家号。
  • 掩膜 ROM(Mask ROM):一种把数据在制造芯片时就「烧死」进去的存储方式——之后不能修改,但读取极快、极省电。Taalas 把 AI 模型的权重直接用掩膜 ROM 刻进芯片,所以推理速度快到 17000 TPS、功耗只有 GPU 的几十分之一。代价是:换模型就得重新造芯片(虽然只需改 2 层掩膜)。
  • 隐形水印(Stealth Watermark):在 AI 生成的文字里嵌入肉眼看不见但计算机能检测的标记,比如用视觉上一样的 Unicode 字符替换常规字符。目的是让 AI 生成内容可被溯源。今天的争议在于:Anthropic 没有公开水印算法,所以它不仅能标记「这是 AI 写的」,理论上还可能记录「是谁让 AI 写的」。
