  1. Claude Ship:三个 agent 把 PR 从评审做到批准,其中一个能自己签字 — 11-23 发布,Code Review 正式版,另两个公测。 新发布

    三件事分别由三个 agent 干:Code Review 找逻辑错误、安全漏洞和没覆盖到的边界,结论按严重度做成行内评论;PR Steward 盯失败的 CI、合并冲突和评审意见,自己推修复 commit——它被设计成不能批准、不能合并,你用 @claude 指挥它、@claude stop 叫停;Claude Approvals 读你写的策略文件 .claude/approvals.yml,按策略决定能不能自己批。Anthropic 自己的说法是「一个更聪明的 CODEOWNERS」。

    策略文件才是重点,也是你真正要写的东西:比如计费这种关键服务仍要求作者之外两个人审、其中一个必须来自支付团队;一般代码在 Claude 评审干净的前提下人类审批降到一个;纯文档改动 Claude 可以自己批。合不合得进去最终还是由你 GitHub 的分支保护规则说了算,这条边界没被动。

    个人也能用的那部分:任意付费计划在 Claude Code 里跑 /ship——提交、推送、开 PR、评审、再去啃反馈和挂掉的检查,合并仍然你自己点。要求 Claude Code v2.1.330+、GitHub CLI 2.63+、git 2.38+;/ship 在本地跑,最长 7 天,会话要一直开着、电脑不能睡。另外注意:你自己定义的 ship / ship-local / steward 同名 skill 或命令会被内置的顶掉、加载不了。

    钱怎么算:/ship 算普通 Claude Code 用量;Claude Ship 走 Team / Enterprise 计划的 GitHub 仓库,按 token 从独立的 usage credits 里扣、管理员可设花费上限。Claude Approvals 没有基础费,但分类器本身要烧 token,而且策略里只要触发 Code Review 就是一次付费评审——哪怕你设成只观察不动手。 符合条件的 Enterprise 可在 2027-01-15 前领至少 $10,000 促销额度,领了要 30 天内用掉。

    自述数据,看看就行:Claude Code 团队 6 月到 9 月合并 PR 翻了一倍多、被 revert 的比例降 40%+、带实质评审意见的 PR 从 16% 涨到 54%、一轮「评审+修」就过的从 65% 涨到 78%、平均评审轮次 2.08 → 1.32;多数 Code Review 跑完要 6~10 分钟。官方 FAQ 自己写了「会用 AI,可能漏掉 bug、安全漏洞或其他问题」。

  2. 智谱 GLM-5.4:把 GLM-5 的 28 层跑两遍,7500 亿参数号称摸到 2~3 万亿的水平 — 11-23 上线,首个 Loop Transformer 架构的 GLM。 新发布

    做法:不是从头预训练,而是拿已经练好的基座继续训练、改造成 Loop Transformer——官方给的理由很实在:权重共享在同等预训练算力下打不过非共享,所以走改造路线。中间 28 层每个 token 过两遍,参数量不变、计算深度翻倍。

    唯一公开的 benchmark 是一个 30B 的消融对照(不是 750B 本体):MMLU-Pro 71.14→74.47、GPQA-Diamond 47.62→56.31、AIME25 19.17→30.42、AA-LCR 40.25→47.73、IFBench 22.31→25.81。值得注意的副作用:平均输出长度在 GPQA-Diamond 和 MMLU-Pro 上降了 10~14%,官方归因为推理搬进了循环的隐式深度里——少吐 token 也是省钱。

    规格:上下文 1M、最大输出 128K、纯文本输出,新增视觉输入,支持多思考档、流式、Function Calling、上下文缓存、结构化输出。模型名 glm-5.4,在 Claude Code 里是 glm-5.4[1m]。非高峰报到 200 token/s、高峰 70~80。

  5. codex sandbox:OpenAI 把 Codex 的沙箱拆出来当独立命令,任何命令都能塞进去跑 — 11-18 工程博客,作者 Michael Bolin。 实战

    最值得抄走的一行:Codex CLI 暴露了一个 codex sandbox 子命令,按指定的 permission profile 跑任意命令——也就是说这套沙箱脱离 agent 会话也能用,你想隔离跑一段不信任的脚本,直接拿它当工具。

速览

值得知道但不用细读的动态

  1. tether:给你不信任的 agent 套一层——沙箱 + 硬预算 + 可重放的 trace — Rust 写的 model-agnostic、MCP 原生运行时,口号是「Run agents you don't trust on infrastructure you do」。它包住任意 agent,记下每一次模型调用、工具调用和策略决定,然后 tether replay 不联网、不花钱地把这条 trace 重跑一遍(可以换个 policy 或 prompt 再跑)、tether diff 指出两次跑哪里分叉。11-21 合进来的 tether eval 更实用:拿录下来的 trace 当回归测试集,对着 eval.toml 断言 outcome、max_steps、max_usd、no_deny、tool_called / tool_not_called、file_contains。重放语义写得很清楚——它压根不跑 agent,只按顺序重发录下来的请求和工具调用,工具结果按「工具名 + 参数」匹配;被拒绝过的调用没有结果可重放,因为那个工具当时根本没跑。 工具

今日术语

  • Loop Transformer(循环 Transformer):让模型的中间几层用同一份权重反复跑几遍,参数量不涨而计算深度涨——相当于「想得更深」而不是「脑子更大」。今天 GLM-5.4(28 层跑两遍)和 Inkling 2 Mini(12 层跑三遍)是两家独立团队同一周的两个样本。注意它省的是内存容量,不省带宽、也不省 KV cache。
  • 双重释放(Double Free):同一块内存被 free 了两次,把内存分配器的内部记账搞乱,攻击者精心构造就能借此改写别处的内存、甚至执行自己的代码。
  • 间接提示注入(Indirect Prompt Injection):攻击者不直接跟模型对话,而是把指令藏在模型「将来会去读」的东西里——网页、PR 评论、依赖的 README、搜索结果——等 agent 读到的那一刻,数据就变成了命令。
  • Permission Profile(权限档案):一份声明「这个进程能读写哪些目录、能连哪些网络地址」的配置,由操作系统而不是程序自己来强制执行。codex sandbox 的三档 read-only / workspace / danger-full-access 就是这个。
  • CODEOWNERS:GitHub 仓库里一个文本文件,写明「哪些路径下的改动必须由谁来审」。Anthropic 把 Claude Approvals 的 .claude/approvals.yml 类比成它的升级版——区别是后者能按条件决定「需要几个人审」甚至「不用人审」。
