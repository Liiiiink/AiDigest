今日新词

  • 硬连线模型 / Hardcore Model(把模型刻进芯片):普通 AI 芯片像通用电脑,权重从显存(HBM)里读;Taalas 的做法是把某个模型的权重直接做成电路蚀刻在硅片上,省掉搬运数据的功夫,速度暴涨十几倍。代价是这颗芯片一辈子只会跑这一个模型,换模型就得重新造芯片。
  • Harness(智能体骨架 / 工作台):模型本身只会「输出文字」,真正让它能读文件、跑命令、调 API 的那套外围代码框架就叫 harness。今天 Muse Code、OneDayAgent、EvolveNet 说的都是同一件事——同样的模型,配不同的工作台,干活能力天差地别。
  • Agentic Index(智能体能力指数):第三方评测机构 Artificial Analysis 的综合榜单,不考「答题准不准」,而考模型作为 Agent 能不能真把多步骤任务干完(用工具、写代码、纠错)。Qwen3.8 Max 今天登顶的就是这个榜。
  • Worktree 并行子 Agent:worktree 是 Git 的功能,能把同一个代码仓库同时签出成多份独立副本。Muse Code 用它让好几个子 Agent 各占一份副本同时改代码,互不打架,最后再合并——相当于一个人指挥一支小队并行开发。
