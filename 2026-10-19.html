今日术语

  • MoE / 激活参数（Mixture-of-Experts / Active Parameters）：模型里养着一大堆「专家」子网络，每个 token 只唤醒其中几个，所以 501B 的模型推理时只算 23B 的量。
  • SWE-Bench Verified：从真实 GitHub issue 里挑出的、人工核验过的编程修 bug 测试集，目前衡量「模型能不能干活」最认的尺子。
  • MCP（Model Context Protocol）：一套标准接口，让 AI Agent 用统一方式调用外部工具和数据源，不用为每个工具单独写胶水代码。
  • ATS（Applicant Tracking System）：招聘方用来自动解析和筛选简历的系统，简历排版太花会被它读成乱码，所以才需要「ATS 可解析性检查」。
