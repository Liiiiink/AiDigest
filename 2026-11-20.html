    编号 SA-CORE-2026-017,11-18 披露。特定条件下匿名攻击者可以调用安装器尝试重装站点,部分配置下直接拿到服务器 RCE。

    来不及升就先堵路径:在 web server 配置或根 .htaccess 里封掉 /core/install.php(Apache 用 Require all denied,nginx 用 location = /core/install.php),同时确认 web server 进程不能写 settings.php、也不能改它的权限——这是触发条件之一。

  2. Ruby 一次补七个内存安全洞,五个有 PoC 能打到 RCE,根因是德语 ß 转大写 — 主角 CVE-2026-132825(Ruby2Shell),一字节堆溢出。 实战

    成因干净得像教科书:Ruby 把 ß 转大写会输出 SS,一个输入字节变两个输出字节,而循环只检查了「还够不够写一个字节」,第二个字节就越过了缓冲区边界。只在 ISO-8859-1、Windows-1252 这类遗留单字节编码下触发。

    另外六个分布在正则引擎和大小写转换:正则编译的 double free 和整数溢出、大小写不敏感匹配的越界读、Regexp#to_s 的堆溢出。

    升级到 4.0.10 / 3.4.13 / 3.3.14。要注意的不只是你自己装的 Ruby——别的产品里捆绑的那份也要一起查。

  3. Gemini API 上线 Tool Retrieval:几百个工具不再全量塞进上下文,闲置的一个只占约 26 token — 11-19 预览版,不额外收费。 工具

    用法只有两步:请求里加一个 tool_search 工具,然后给想缓一缓的工具挂 defer_loading: true。模型仍然看得到每个工具的名字和描述,但参数 schema 不进上下文;要用的时候模型按名字点名,API 当场把完整 schema 加载进来,整个过程在同一个请求里完成。

    限制说清楚:只支持 Gemini 3.6 及以后(含全部 Gemini 4),不支持的模型传 defer_loading 直接 400;必须走 v1beta 的 Interactions API,generateContent 不支持;每个请求只准有一个 tool_search。

    对接 MCP 特别划算:给 mcp_server 工具设 defer_loading: true 会把这台 server 暴露的所有工具一起 defer,不用一个个列。兼容前缀缓存。官方建议是常用的留着、其余全 defer。

    调试友好:工具搜索调用、搜索结果、函数调用都会记进 interaction.steps,能直接看出是不是你的工具描述写得太烂导致搜不中。
