今日术语

  • KV 缓存（KV Cache）：大模型生成时把已算过的注意力中间结果存起来复用，省掉重复计算——今天 Cloudflare 那起事故就是这块显存里的页没被正确清掉，上一个用户的内容被下一个用户读走了。
  • PD 分离（Prefill/Decode Disaggregation）：把「读完整个提示词」和「逐 token 吐字」拆到不同机器上跑，各自用最合适的硬件；好处是吞吐高，代价是两边的状态同步一旦出错就容易串数据。
  • RLVR（可验证奖励的强化学习）：训练推理模型时，不靠人给偏好打分，而是用一个程序自动判对错（比如数学题答案是否正确）当奖励信号——便宜、可规模化，是 R1 之后的主流路子。
  • SARIF：一种静态分析结果的通用 JSON 格式，CI 和 IDE 都认；工具输出 SARIF 就能直接把告警挂到 GitHub 的 Security 标签页或编辑器的问题面板里。
  • 指数时间假设（Exponential Time Hypothesis, ETH）：一个比 P≠NP 更强的猜想，断言 3-SAT 这类问题不存在亚指数时间算法；很多「这个问题最快也就这样了」的结论都是以它为前提推出来的。
