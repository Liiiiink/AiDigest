今日术语

  • System One Model:一种输出结构化决策值（而非自然语言文本）的 AI 模型——把模型直接当成函数调用来用，不能生成字符串所以不会「幻觉」。
  • Denial of Wallet (DoW):不搞崩你的服务，但通过海量 AI API 调用让你的账单爆掉的攻击方式——比 DDoS 更难察觉，因为它看起来就像正常用量增长。
  • Harness:AI Agent 的运行框架，管理模型调用、工具选择、上下文和任务流程——可以理解为 Agent 的「操作系统」。
  • Token 经济学:理解每次 AI API 调用消耗多少 token、花多少钱、值不值——正在变成和「会用 Git」一样基础的开发者成本意识。
