今日术语

  • .pth 文件(Python 路径配置文件):放在 site-packages 里的一种小文件,Python 每次启动都会读它、并执行其中以 import 开头的行。本意是给包注册搜索路径用的,今天这起投毒正是把窃密代码挂在这里——所以「我没 import 那个包」救不了你。
  • Trusted Publishing(可信发布):PyPI 的一种发布方式,用 CI 的短期身份凭据代替长期 API token 来上传包,并留下「这个包是从哪个仓库的哪条流水线出来的」的来源证明。今天那两个恶意 wheel 恰恰没有这个证明,这就是一个可以自动化检查的信号。
  • OIDC Token(GitHub Actions 的短期身份令牌):CI 作业运行时由 GitHub 签发的一张临时身份证明,用来免密码换取云厂商的访问权限。它被偷了,等于攻击者能以你的流水线身份去拿云资源。
  • Provider Routing(供应商路由):同一个模型往往有多家可以跑(比如 Claude 既在 Anthropic 也在 AWS Bedrock),网关在这些部署之间分流和故障切换,而不改变你用的是哪个模型——和「自动换一个更便宜的模型」是两回事,别混。
