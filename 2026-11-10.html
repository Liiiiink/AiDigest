速览

值得知道但不用细读的动态

  1. OpenAI 公开 Control Room:给内部研究集群装的全局 kill switch,从下令到停住最多 35 秒 — 11-09 发布,对自己跑 agent 集群的人来说这是一份可抄的架构。 观点

    做法是把开关放在推理层而不是业务代码里:workload 启动时申请一个 job_id,之后每次推理请求都带着它,推理引擎在回答前先问 Control Room 要许可,job 被停掉就直接拒绝、模型不再往下吐。这样所有研究推理都必须过这道授权检查,而不用指望每个 workload 自己实现得对。失败即拒(fail closed)——Control Room 挂了或被篡改,所有推理请求一律拒绝。35 秒的延迟来自授权缓存层,官方说在往零压。注意它停的是输出,研究进程本身可能还活着,引擎对其他授权 job 照常服务。

今日术语

  • fast mode(快速模式):同一个模型,用更贵的单价换更快的出 token 速度。Fable 5.2 这档是基础价的两倍换最多 2.5 倍速度——适合交互式等结果,不适合跑批。
  • 无障碍树(Accessibility tree):浏览器为读屏软件生成的那棵「页面语义结构树」,只有角色、名字、状态,没有样式和 DOM 噪音。喂给 agent 比喂 HTML 省几个数量级的 token,也不会因为改了 class 名就失效。
  • fail closed(失败即拒):安全组件挂掉时,系统选择「一律拒绝」而不是「一律放行」。反面是 fail open——权限服务一宕机大家都能进,这是事故报告里的常客。
  • information barrier(信息隔离墙):金融机构内部强制隔离不同业务线信息的合规要求(比如投行部门不能把客户并购消息漏给交易台)。它限制的不只是人聊天,也包括工具能读到什么数据——这正是高盛这次收权限的理由之一。
  • StyleX:Meta 的编译期 CSS-in-JS 方案,样式在构建时就算成静态 CSS,运行时不做样式计算。和 Tailwind 同属「原子化 CSS」思路,但写法是 JS 对象、带类型。
