今日术语

  • MCP(Model Context Protocol):让模型和外部工具、数据源对话的标准协议。装一个 MCP server 等于给 agent 开了一扇通往某个系统的门——所以谁替你装、连到哪,是安全问题。
  • session-start 钩子(hook):编码 agent 每次启动会话时自动执行的脚本。因为会无提示运行,正常流程要求你手动确认一次它的哈希值,确认过的才算「可信」。
  • 本体 / 语义层(Ontology / Semantic layer):一份机器可读的「业务词典」,写明「活跃用户」到底对应哪张表哪些条件。垫在数据库和 agent 之间,让模型别自己猜口径。
  • prompt 缓存 TTL(Time to live):缓存住的提示词前缀能留多久。留得久、命中率高但写入贵,所以是个算账题,不是开了就赚。
  • 文本水印(Text watermarking):生成时轻微偏置模型的用词选择,留下一种统计上可检测、肉眼看不见也删不掉的模式,用来标明「这段是 AI 写的」。
