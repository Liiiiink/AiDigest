本周热点

找洞的速度上来了,接住的那头没跟上

Brotli 越界写 CVE-2026-111497:所有解 Content-Encoding: br 的东西一锅端

  • 发生了什么:DecodeBlockTypeAndLength() 只返回一个 bool,调用方分不清「流坏了」和「数据还没来」,快路径干脆把返回值丢了——构造一次失败的 block switch 就能带着陈旧状态继续解码并越界写。Brotli 1.0.3~1.2.0 全中,Node、Python、Bun、Envoy、Istio、curl 全在射程内。最阴的是 Python:只要装了 Brotli 包,requests / httpx / aiohttp / Scrapy 不用你 import 就会自动解。
  • 凭什么算热点:CVSS 9.2,属于「不处理会出事」那一类;修复版本横跨六个生态同步发布(Node 22.23.4 / 24.22.1 / 26.12.1、Bun 1.4.4、Python Brotli 和 brotlicffi 1.2.1、Envoy 1.40.0 系、Istio 1.29.9 系、上游 1.2.1),这个铺开面本身就是证据;而受影响的 PyPI 包两个月下载 8280 万次,截至 10 月 23 日 advisory 库还没收录——工具查不出来,只能人工查。
  • 你该不该动手:立刻试。具体就两条命令:pip show Brotli brotlicffi 看版本,node -v 对一下修复版本。升不动就直接卸载 Brotli 包(会优雅退回 gzip),或在反代上拒掉 br。这是本周唯一一件「今天不做,明天可能真出事」的事。

LiteLLM 1.107.0 被投毒:专偷 Claude Code / Cursor / Copilot / Gemini CLI 的 token

  • 发生了什么:攻击者只在 pyproject.toml 的 maturin 段加了一行 data = "cook"(sdist 里看不到这个目录,拿 rc2 做依赖 diff 完全看不出异常),装完往 site-packages 塞 cook.pth / cook.py / sitecustomize.py——于是这台机器上任何 Python 进程启动都会执行它,哪怕你从没 import 过 litellm。偷的东西按名单来:SSH 私钥、AWS/Azure/GCP 凭证、K8s token、CI 密钥、浏览器密码、shell history,以及 Claude Code、Cursor、Copilot、Gemini CLI、HF 的 token,外加一个每小时从 GitHub 读新 C2 地址的常驻后门。只有 1.107.0 正式版中招(1.106.2 和两个 rc 干净),已下架。
  • 凭什么算热点:这条线三天里被三份日报接力提到——10-21 GitHub 上线 Package Firewall(npm 装包要先过闸、可配冷静期)、10-22 投毒爆发、同日 gh CLI 上线会过期自动刷新的 OAuth token,10-22 的日报条目自己就把后两件串了起来。而且这是攻击目标的一次明确转向:AI 编码工具的 token 已经被写进窃取清单,和 SSH 私钥并列。
  • 你该不该动手:立刻试。查那三个文件 + 杀掉 PPID 为 1 的游离 Python 进程,中招了就全量轮换凭证。没中招也别放过这次——把 gh CLI 换成会过期的 token、给依赖装上冷静期,这两件事做完之后,下一次投毒你大概率能躺过去(投毒包的生命周期通常只有几十小时)。教程在本期末尾。

「省 token」这周有了两个新打法:拆判断,和让工具自己闭嘴

先说一个我没单独收的背景事实:四个月里 OpenAI 和 Anthropic 把推理价格砍掉最多 80%,GPT-5.6 Luna 从 $1/$6/$0.10 降到 $0.20/$1.20/$0.02;而对 agentic coding 来说缓存读取占总 token 开销的 96~99%,所以 Fable 5.1 缓存读取降 75% 约等于总成本降 70~75%(minimaxir 的拆解)。这个数字值得你今天就拿去重做成本模型,但它只有一篇分析支撑、一天出现,按本周报的标准还不够格单列。真正结构性的变化是下面两条——省钱的办法从「换个便宜模型」变成了「这段活儿根本不该交给通用模型」。

OpenAI Decisions API:输出一分钱不收的专用决策端点

  • 发生了什么:基于 GPT-6 Luna,你给一个问题 + 允许的答案集 + 上下文,它只返回三类结果之一——predicate(条件成立的概率)、choice(选项 + 概率和置信度)、score(按有序 rubric 打分)。因为不生成自由文本,所以 $0.10/百万输入 token、缓存后 $0.01、输出不收钱,比同一个模型走 Responses API 快 10 倍,一次能问 400 个问题,已 GA。
  • 凭什么算热点:48 小时内 OpenAI、Cloudflare、微软、蚂蚁各发了一个决策模型——四家独立动作撞在一起,这是典型的「这类东西的玩法变了」而不是「又一个同类工具」。Cloudflare 的 Clef 直接开了权重:27B 中位延迟 209.3ms、9B 的 Clef-Flash 38.8ms,一次前向吐各选项概率,不生成文本也就不用解析输出。HN 上的主流评价是「这颗果子低垂了好多年」——注意这是嫌它来得太晚,不是嫌它没用。
  • 你该不该动手:排进这个月。先去翻你代码里那些「让 GPT 判断一下这条工单该转给谁 / 这段内容违不违规 / 要不要转人工」的调用——凡是答案集有限的,都是候选。这类调用通常跑在热路径上、量大、而且你现在为它付的是完整的输出 token 钱。想自己托管就拿 Clef 的权重,不想折腾就走 Decisions API。

DuckDB 2.0.0 LTS:专门给 coding agent 加了个输出模式,模型要读的输出少 59%

  • 发生了什么:支持到 2027 年 10 月的 LTS 版。新的 Quack 协议让 DuckDB 能跑成客户端-服务端(CONNECT 一条语句连远端,也支持 Postgres/MySQL),Parquet/CSV/原生存储改成后台异步读,新增一等公民 VARIANT 类型、触发器、带精确位置报错的 PEG 解析器。最对味的是 Agent Mode——CLI 检测到自己被 coding agent 驱动,就自动切紧凑输出和 JSON 报错,实测让模型要读的输出少 59%。
  • 凭什么算热点:两条。一是结构性——这是第一个主流数据库把「我的输出是给模型读的」当成一个一等公民场景来做,省 token 的责任第一次落到了工具那一侧,而不是让你在 Agent 里写「请简洁输出」。二是强制性:存储格式不向下兼容,2.0 写的文件旧版本读不了,这是个你必须排期的破坏性变更。
  • 你该不该动手:排进这个月,但分两步。Agent Mode 现在就可以在本地试,成本几乎为零、收益直接可测(让 Agent 跑同一组查询,对比上下文消耗)。生产库的升级官方自己建议等 11 月第一个补丁版——存储格式不可逆,别急这两周。更值得带走的是那个思路:你自家的 CLI 工具,是不是也该有个 Agent Mode?

审查这件事,正在从「让模型看看」变成「跑规则」

Cloudflare 开源自家漏洞挖掘 harness 的底座:一个六阶段的安全审计 skill

  • 发生了什么:npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit 装好,对着代码库说「security audit this codebase」即可。设计上最值得抄的是三点:查证的 Agent 绝不是发现问题的那个 Agent;结论强制分三档——confirmed(有完整源码链路)/ needs_validation(必须写明到底哪个事实没查实,且不许给严重性)/ rejected;还会区分「主防御已拦住」和「纵深防御有缺口」来避免刷噪音。多次运行会基于上次的 ledger 补盲区,MIT。
  • 凭什么算热点:GitHub 上 48,867 star(10-27 实测)。但更硬的证据是同一周出现了至少四个把「判断」写死成规则的东西:这个 skill 的三档结论、impeccable 的 62 条确定性检测规则、hallmark 的确定性 lint、以及 Anthropic 那套形式化验证流水线(123 个库、239 个入口点)。四件事都在做同一个动作——把「我觉得这里有问题」换成「这条规则命中了,证据在这」。
  • 你该不该动手:立刻试,但重点不在跑它。它对你最大的价值是那套结论分级:你现在的 AI code review,大概率是把「确定的 bug」和「模型觉得可疑」混在一张列表里发给人看,于是 reviewer 很快就学会了全部忽略。把 needs_validation 这一档单独拎出来、强制写明缺哪个事实、并且不许标严重性——这条规则今天就能抄进你自己的 review 流程,不需要装任何东西。

impeccable 冲到 8.95 万星:「AI 写的前端像模板」被当成一个可测的缺陷

  • 发生了什么:1 个 skill、24 条命令、62 条确定性检测规则,专盯 Inter 字体、紫蓝渐变、卡片套卡片、彩色底上的灰字、过时的弹性缓动这些模型因为吃同一批 SaaS 模板而反复吐出来的东西。npx impeccable install 自动识别 Claude Code / Cursor / Codex / Copilot / Grok,npx impeccable detect 不挂 Agent 也能单独扫。同周还有 Together AI 的 hallmark,思路几乎一样:从 48 套主题里挑,然后拿确定性规则在 8 个视口宽度下逐个 lint 那些 AI 惯犯(标题上方多余的 eyebrow 标签、大标题里染色的那一个词、纯装饰空框、点了没反应的表单),最后由一个全新上下文的子 Agent 复看渲染结果做终审。
  • 凭什么算热点:日报 10-25 记的是 8.69 万星,我 10-27 实测 89,505 星、5,325 fork——两天涨了约 2,600 星。同日 GitHub trending 上还有另外几个同类 design skill。这是本周采用度数字最硬的一条。
  • 你该不该动手:做前端就立刻试,不做前端就只抄做法。抄的是两点:一,你领域里那些「AI 的惯犯」是可以穷举成规则的,写下来比每次在提示词里喊「不要千篇一律」有用得多;二,让一个全新上下文的子 Agent 做终审——写代码的那个 Agent 已经被自己的上下文说服了,它复查不出自己的问题。这两点和上面那条 security-audit skill 是同一个道理。

  • Kimi K3.1 Pro / MiniMax M3.1 Flash / LFM2.5-24B-A2B 三连发 — 跑分发布,明确不收。K3.1 Terminal-Bench 65.7% 离 Opus 5.5 不到 1 个点确实好看,但权重没放、你现在动不了手;MiniMax 开了权重,可 DeepSWE 73.7% vs Opus 5 的 74.0% 属于追平而非改变量级。等 K3.1 开权重——Artificial Analysis 说那会把开放权重和闭源头部的差距从 12 分压到 3 分,那才是量级变化。
  • Claude Duet(Agent 从「你问它答」转成「它找你」) — 产品形态的转向是真的,但 research preview、仅美国、Team/Enterprise 还没有,而且没有单独的 API 或 SDK——开发者现在唯一的切口是写 connector 和 skill。等出 API,或者等它开放到 Team 档。
  • GitHub 用 AI 把 Copilot 运行时 80 万行从 TS 重写成 Rust(14.5 周,启动从 5.25 秒降到 292 毫秒) — 读起来最精彩的一篇,但它是一次性的工程叙事,你没有那 14.5 周也没有那个团队。真正可复用的只有一句:不做并行重写一把切换,而是逐个组件替换 + 中间架一层临时互操作层(峰值 2019 个导出,最后整层拆掉)。等看到中小团队用同样方法做完并复盘,再把它当方法论收。
  • Anthropic 的形式化验证流水线(123 个库、239 个入口点、约 1.8 亿行证明) — 「证完的 fuzz 入口点可以不用再 fuzz 了」是个真结论,证明过程也确实捞出了多年 fuzzing 没发现的 bug。但适用面是 C 解析库这类输入驱动、无状态、可穷尽的代码,你的业务代码不在这个范围里(Copilot 那篇复盘的原话:取消、重试、背压这类场景编译器根本验不了)。等有人把它用在非解析器类代码上并给出成本数字。

动手教程:给你这台机器做一次「AI 工具凭证」体检,再给依赖装上冷静期

本周两条安全热点的直接应对——30 分钟,查完一次,以后自动躺过大半投毒

你将做出:一份确认过的「我没中招」结论,外加一道让下次投毒自动失效的闸门。

准备:

  • 一个终端;装过 Python 包的机器(有 Node 项目就再多做一步)
  • 不需要 API Key、不需要装任何新工具
  • 如果你用过 Claude Code / Cursor / Copilot / Gemini CLI,这一步对你尤其不可跳过——本周那次投毒的窃取清单上点名了它们

跟着做:

  1. 查 LiteLLM 投毒的残留。先问出你的 site-packages 在哪,再看里面有没有那三个文件:
    ```bash
    python3 -c "import site; [print(p) for p in site.getsitepackages()]"
    # 对上面打印出的每个目录 D,执行:
    ls -la D/cook.pth D/cook.py D/sitecustomize.py 2>/dev/null
    ```
    什么都没打印出来 = 干净。打印出任何一个文件,就按「中招」处理:全量轮换凭证(SSH key、云凭证、CI 密钥、以及所有 AI 工具的 token),别只删文件。
    顺手确认一下版本:pip show litellm——只有 1.107.0 正式版中招,1.106.2 和两个 rc 是干净的。
  2. 揪出游离的后门进程。那个后门会常驻并每小时去取新的 C2 地址,特征是父进程已经没了(PPID 为 1):
    ```bash
    ps -axo pid,ppid,command | awk '$2==1 && /[p]ython/'
    ```
    列出来的每一条都要能说清楚它是什么(很多是正常的后台服务),说不清的就杀掉并回到第 1 步重查。
  3. 查 Brotli。这是本周那个 CVSS 9.2,而且 Dependabot 和 pip-audit 当下查不出来,只能手查:
    ```bash
    pip show Brotli brotlicffi # 要 >= 1.2.1
    node -v # 要 >= 22.23.4 / 24.22.1 / 26.12.1
    ```
    版本低了又一时升不动,最快的止损是直接卸载 Brotli 包——requests / httpx / aiohttp 会优雅退回 gzip,不会炸。服务端的话,在反代上拒掉 Content-Encoding: br 也行。
  4. 装上冷静期,让下一次投毒自动失效。投毒包的生命周期通常只有几十小时,晾一下就躲过大半。pnpm 已经内置了这个开关,在 pnpm-workspace.yaml 里:
    ```yaml
    minimumReleaseAge: 4320 # 单位是分钟;默认 1440(24 小时),这里调到 3 天
    minimumReleaseAgeExclude: # 需要立刻拿到新版的包单独放行
    - "@myorg/*"
    ```
    先确认你没把它关掉(默认值就是 1440,很多人不知道),再按你的发布节奏决定要不要调高。企业版用户可以同时开 GitHub Package Firewall(npm,公测期免费),它横在 CI runner / 编码 Agent 和上游仓库之间,下载前先查 Advisory 数据库和 attestation 降级。
  5. 把 gh CLI 的长期 token 换成会过期的。默认那个永不过期的 OAuth token 一旦被捞走就是永久通行证——本周那次投毒正好演示了它怎么被捞走。按 changelog 里的 opt-in 步骤切成短期 + 自动续期,被偷的那份很快自己失效。
做完你会:有一条可以写进团队 wiki 的检查清单,以及一个认识——依赖准入正在从个人自觉变成一个有配置项、有预算、有岗位的平台能力。下一步可以把第 1~3 步写成一个脚本挂进 CI,或者直接包成一个 skill 让 Agent 自己定期跑。
