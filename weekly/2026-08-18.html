模型精讲:推理模型(Reasoning LLM)——会"打草稿"的大模型是怎么炼出来的

o1、DeepSeek-R1 这类"会先想再答"的模型,强的不是脑子更大,而是被允许"在纸上打草稿"

核心看点:推理 = 生成中间步骤再作答;炼出这种能力有四条路线——推理时计算扩展、纯强化学习、SFT+RL、蒸馏——DeepSeek-R1 把它们全部公开了。

它是什么

  • 推理模型(Reasoning LLM):回答前先生成一长串中间推理步骤(俗称"思考过程"),再给出最终答案的模型。
  • 类比考试:普通模型像要求"直接写答案"的学生,推理模型像被允许打草稿、验算的学生——数学题立刻强一大截。
  • 代表选手:OpenAI o1/o3、DeepSeek-R1、Qwen 的 QwQ 等。

为什么重要

  • 复杂任务分水岭:数学、编程、逻辑谜题这类多步任务上,推理模型把天花板抬高了一个量级。
  • 但不是万金油:摘要、翻译这类简单任务用它,纯属"杀鸡用牛刀"——更贵、更慢、更啰嗦,还可能"想太多"反而答错。学会按任务选模型,是 2026 年的基本功。
  • 方法已公开:DeepSeek-R1 把完整训练管线摊牌了,这篇文章正是以它为案例拆解——看懂 R1,就看懂了整个推理模型赛道。

它是怎么炼出来的:四条路线

  1. 推理时计算扩展(Test-Time Compute):不改模型,只在"答题时"加钱。一句 think step by step(思维链 / CoT 提示)让模型输出中间步骤;再配多数投票(让模型答 10 次取票数最高的)等策略。o1 疑似大量依赖此路线——这解释了它为什么贵:账单按"草稿纸"算。
  2. 纯强化学习(RL):R1-Zero 的震撼发现——推理能力可以从纯 RL 中"涌现"。只给两种奖励:准确率奖励(数学/代码答案可程序化验证对错)+ 格式奖励(思考过程放在规定标签里),不做任何示范微调,模型自己就学会了打草稿,甚至出现自我纠正的 "Aha! 时刻"。
  3. SFT + RL(旗舰路线):R1 的完整配方——用 R1-Zero 生成"冷启动"数据做指令微调(SFT) → 一轮 RL(加一致性奖励防止语言混杂)→ 再收 60 万条 CoT 样本做第二轮 SFT → 最后一轮 RL。这是当前炼高性能推理模型的标准答案。
  4. 蒸馏(Distillation):用大模型生成的思考数据去微调小模型。实验结论很反直觉:对小模型来说,蒸馏远比自己搞纯 RL 划算;但局限也明显——它依赖已有更强模型,无法推动前沿。
进阶点一(为什么"想太多"会错):推理模型在简单问题上会陷入过度思考(overthinking)——草稿越打越长,把自己绕进死胡同。这催生了"推理努力程度控制"(low/medium/high 档位)这类新研究方向。
进阶点二(低预算复现潮):推理能力不再是大厂专利——Sky-T1 用 1.7 万条 SFT 数据、约 $450 训出 32B 推理模型;TinyZero 以不到 $30 在 3B 小模型上复现了 R1-Zero 的纯 RL 路线;Journey Learning 则在训练数据里故意保留"错误推理 + 纠正过程",教模型学会自我改错。

动手教程:用 smolagents 写你的第一个 Agent(10 行代码)

Hugging Face 官方轻量框架:让模型自己写 Python 代码来调工具,看得见完整的"思考→行动→观察"循环

你将做出:一个能自己上网搜索、自己写代码调用工具的迷你 Agent——上一期精讲讲透了 Agent 的"内部构造",这一期亲手攒一个出来。

准备:

  • Python 3.10+ 和 pip(无需 GPU,模型跑在云端)。
  • 一个免费 Hugging Face 账号:注册后到 Settings → Access Tokens 创建一个 token,然后在终端 export HF_TOKEN=你的token(新账号自带免费推理额度,足够跑本教程)。

跟着做:

  1. 安装(约 1 分钟):

    ```bash

    pip install "smolagents[toolkit]"

    ```

  2. 最小 Agent(5 行核心代码,来自官方 README):新建 my_agent.py

    ```python

    from smolagents import CodeAgent, WebSearchTool, InferenceClientModel

model = InferenceClientModel() agent = CodeAgent(tools=[WebSearchTool()], model=model, stream_outputs=True)

agent.run("一只豹子全速跑过巴黎艺术桥需要多少秒?") `` 运行 python my_agent.py`,你会看到它现场打印思考过程:先想"豹子时速多少、桥多长"→ 自己写 Python 代码调搜索工具 → 拿到结果再算除法——这就是上期讲的 Agent Loop,这次是你亲手跑起来的。

  1. 给它造一个你自己的工具:CodeAgent 的精髓是"模型用代码调工具"。自定义工具只要一个 @tool 装饰器(官方文档示例):

    ```python

    from smolagents import tool

@tool def model_download_tool(task: str) -> str: """ 返回 Hugging Face Hub 上某任务下载量最高的模型名。

Args: task: 任务类型,如 "text-to-video"。 """ most_downloaded = next(iter(list_models(filter=task, sort="downloads", direction=-1))) return most_downloaded.id `` 三个硬性要求:**函数名清晰、输入输出都有类型标注、docstring 里带 Args: 说明**——它们会被自动注入 Agent 的系统提示词,模型靠这三样"看懂"你的工具。把 model_download_tool 加进 tools=[...]` 再提问即可。

  1. 想继续深造:Hugging Face 免费的 Agents Course 在 Unit 1 就用 smolagents 带你做"第一个 Agent",后续还有 LlamaIndex、LangGraph、Agentic RAG,Unit 4 完成最终项目可拿官方认证(有学生排行榜)。
做完你会:直观理解"模型 + 工具 + 循环"如何变成一个会干活的 Agent,并拥有一个可无限扩展的模板——换工具(查天气、读文件、调你自己的 API)就是换一行 tools=[...]。下一步可探索:把模型换成 LiteLLMModel 接其他厂商 API;或读官方建议,把 Agent 代码放进 Docker/E2B 沙箱再放开手脚(本地执行器不是安全边界)。
