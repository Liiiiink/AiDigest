模型精讲:Coding Agent 是怎么工作的(工具、记忆与 Agent Loop)

你天天用的 Claude Code / Codex,核心不是"更聪明的模型",而是模型外面那层"会干活的壳"

核心看点:Agent = 模型 + 工具 + 记忆 + 环境反馈组成的一个循环;很多看似"模型变聪明"的体验,其实是这层壳(Harness)在替模型管理上下文。

它是什么

先把四个常被混用的名词分清:

  • LLM:只会"预测下一个词"的裸模型,是地基。
  • 推理模型(Reasoning Model):被专门优化成"先输出思考过程、再作答"的 LLM。
  • Agent(智能体):"用模型 + 工具 + 记忆 + 环境反馈组成的一个循环"——模型不再只说一遍话,而是反复观察、行动、再看结果。
  • Harness(壳 / 脚手架):包在 Agent 外面的软件,负责管理上下文、工具调用、权限和流程。

作者的汽车类比很妙:LLM 是发动机,推理模型是更强的发动机,而 Harness 是方向盘和仪表盘——发动机再强,没有方向盘也到不了目的地。

为什么重要

  • 2026 年 AI 的主战场早已不是"聊天",而是"做事":写代码、查资料、操作软件。做事靠的就是 Agent。
  • 文章里最扎心的一句:"很多看起来像'模型质量'的东西,其实是上下文质量。" 同一个模型,放进好的 Harness 里表现判若两人——这解释了为什么不同 Agent 产品体验差距巨大。
  • 对学习者:看懂 Harness 的构造,你就不再只是"用"AI,而是能判断一个 Agent 产品到底强在哪、噱头在哪。

它是怎么工作的:一个循环 + 六个零件

Agent Loop(智能体循环):Observe(观察环境)→ Inspect(分析)→ Choose(选下一步/调哪个工具)→ Act(执行)→ 结果回到观察,如此往复,直到任务完成。

围绕这个循环,Harness 有六个核心组件:

  1. 实时仓库上下文:开工前先收集"稳定事实"(git 分支、目录结构、README / AGENTS.md),避免模型每次都从零瞎猜。
  2. 稳定提示词前缀 + 缓存复用:系统指令、工具说明等几乎不变的部分放在提示词最前面,配合 Prompt Caching 复用——又快又省钱。
  3. 结构化工具 + 校验 + 权限:不让模型"即兴写命令",而是给一份带输入 Schema 的命名工具清单(读文件 / 搜索 / 跑命令 / 改文件 / 派生子 Agent);执行前先程序化检查:是已知工具吗?参数合法吗?需要用户批准吗?路径在工作区内吗?
  4. 上下文压缩:反复读文件、日志刷屏会让上下文爆炸。手段包括裁剪(Clipping)超长输出、总结旧对话、去重重复读过的内容。
  5. 转录 + 记忆 + 断点续传:完整 Transcript 以 JSON 落盘(可恢复会话);另维护一份精炼的工作记忆(当前任务、关键文件、笔记),随对话不断更新压缩。
  6. 有边界的子 Agent:主 Agent 可派生子 Agent 干杂活(找符号定义、查配置),但子 Agent 上下文更紧、权限更小(只读、限制递归深度),防止多个 Agent 乱改同一批文件。
进阶点一(省钱原理):"稳定前缀"为什么能省钱?因为推理时的 KV Cache / Prompt Caching 机制——前缀不变,之前算过的 Key/Value 可以直接复用,不必重算。这正是上一期讲的注意力机制在工程上的延伸。
进阶点二(设计哲学):约束带来能力。命名工具、参数校验、权限闸门、沙箱,看似"限制了模型自由",实则是可靠性的大半来源——自由聊天的模型很强,但被圈好边界的模型才有用。

动手教程:用 nanochat 从零训练一个你自己的 ChatGPT

Karpathy 的极简项目:三条命令,亲手走完"分词器 → 预训练 → 微调 → 对话"全流程

你将做出:一个从你手里训出来、能在命令行里聊天的小 GPT。完整版能力达 GPT-2 级别(评测分数超过 2019 年原版);免费快速版可在自己笔记本上跑通整个流程。

准备:

  • 一台电脑(Mac / Linux / Windows 配 WSL),装没装 Python 都行——依赖由 uv 自动管理。
  • 免费路线:纯 CPU 或苹果芯片,跑缩小版模型,几十分钟走完流程(效果弱,但全流程一步不少)。
  • 完整路线(可选,要花钱):租云 GPU。8×H100 约 1.5~2 小时,按需约 $48、竞价实例约 $15;单卡 GPU 也能跑,时间约 8 倍。对照:2019 年原版 GPT-2 训练要 168 小时、约 $43,000。

跟着做:

  1. 装环境(约 5 分钟):

    ```bash

    git clone https://github.com/karpathy/nanochat.git

    cd nanochat

    uv sync --extra cpu # 有 NVIDIA 显卡则用:uv sync --extra gpu

    source .venv/bin/activate

    ```

  2. 快速跑通全流程(免费,几十分钟):

    ```bash

    bash runs/runcpu.sh

    ```

    一个脚本自动完成:训练分词器 → 预训练 → 微调 → 评测。建议放在 screen / tmux 里跑,防止断线。

  3. 跟它聊天:

    ```bash

    python -m scripts.chat_cli

    ```

    用你亲手训出的权重对话——作者形容"有点像跟幼儿园小朋友聊天",会答话、会写诗,也会一本正经地胡说八道。

  4. (可选,进阶)完整版 speedrun:在租来的 8×H100 上跑

    ```bash

    bash runs/speedrun.sh

    ```

    约 1.5~2 小时得到 GPT-2 级别模型。想快速试验可加 --depth=12,几分钟训一个 GPT-1 大小的小模型;显存不足就调小 --device-batch-size(32 → 16/8/4/2/1)。

做完你会:亲手走完一个 ChatGPT 诞生的完整流水线——这是"看 100 篇新闻"都换不来的直觉。整个项目只有一个 --depth 参数控制模型大小,其余超参数按"计算最优"自动推导;代码专为可读性设计,没有巨型配置对象和 if-else 怪兽。下一步可探索:通读源码理解每个阶段、换自己的语料微调出独特风格,或对照上期 Ollama 教程体会"训练"与"推理"的完整闭环。
