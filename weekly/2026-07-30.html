模型精讲:Scaling Laws(缩放定律)

大模型为什么"越练越强"是能提前算出来的?

核心看点:训练损失随模型、数据、算力呈幂律下降——这意味着大厂在按下「训练」按钮之前,就能预测烧掉几千万美元后模型会变多聪明。

你有没有发现,这几年 AI 的进步有一种奇怪的"确定性":GPT-2 到 GPT-3 到 GPT-4,每一代都把参数和数据量放大一个数量级,然后能力就真的上了一个台阶。这不是碰运气,而是背后有一条经验定律在兜底——Scaling Laws(缩放定律):模型的训练损失(可以粗略理解为"犯错率")与参数量 N、训练数据量 D、算力 C 之间呈幂律关系。所谓幂律,就是在"对数-对数坐标图"上,损失和规模的关系近似一条直线:规模每扩大 10 倍,损失就按固定比例下降一格。打个比方:它像健身的"进步曲线"——新手期进步飞快,之后每进一步都要付出成倍努力,但这个衰减节奏是稳定、可外推的。OpenAI(Kaplan 等,2020)最早系统提出这条定律,DeepMind 随后用 Chinchilla 论文(2022)修正了关键细节。

Chinchilla 的核心结论一句话:模型和数据要"门当户对",等比放大。这就像给车配发动机:光换更大的发动机(堆参数)却不加更多油(数据),车跑不远;反之亦然。Chinchilla 证明,在同样算力预算下,最优策略是参数翻倍、训练 token 也翻倍——它用只有 Gopher 1/4 的参数、4 倍的数据,在相同算力下全面反超了 Gopher。这个结论直接改写了后来所有主流大模型的训练配方(比如 Llama 系列明显"数据管够")。进阶点一:当数据不够、只能反复训练同一批数据时(Muennighoff 等 2023),重复数据的价值会指数衰减,此时"多训几轮"比"继续堆参数"更划算。

进阶点二:为什么偏偏是幂律?一个有趣假说(Michaud 等 2023)认为,知识是一块块离散的"量子技能",而这些技能在数据中的出现频率本身就服从幂律分布——模型先学会常见技能、再啃稀有技能,损失自然走出一条平滑的幂律曲线。读完后你再回头看本期教程:你亲手训练的小 GPT,损失从 4.x 一路降到 1.x 的那条曲线,就是这条宇宙级定律在你笔记本上的微缩演示。

动手教程:用 nanoGPT 亲手训练你的第一个 GPT

不到 600 行核心代码,在你的电脑上训练一个会"写莎士比亚"的迷你 GPT

你将做出:一个从零训练出来的字符级 GPT,能生成莎士比亚腔的"伪英文剧本",并亲眼看到训练损失一路下降。

准备:一台能跑 Python 的电脑(Mac / Linux / Windows 均可;有 GPU 更快,纯 CPU 或 Apple Silicon 也能跑)。先装好 Python 3.9+ 和 git。不需要任何账号,全部免费。

跟着做:

  1. 拉取代码并装依赖(约 2 分钟):

    ```bash

    git clone https://github.com/karpathy/nanoGPT.git

    cd nanoGPT

    pip install torch numpy transformers datasets tiktoken tqdm

    ```

  2. 准备数据集:运行 python data/shakespeare_char/prepare.py。它会下载约 1MB 的莎士比亚全集,并切成一个个字符,打包成 train.bin 训练文件。
  3. 开始训练:有 GPU 的话直接运行 python train.py config/train_shakespeare_char.py,约 3 分钟训完;纯 CPU 或 Mac 笔记本就加参数缩小模型,例如 --device=cpu --compile=False --block_size=64 --n_layer=4 --n_head=4 --n_embd=128 --max_iters=2000(Mac 可把 --device=cpu 换成 --device=mps 用 Metal 加速)。盯着屏幕:你会看到 loss 从 4.x 一路往下掉——这就是上一篇 Scaling Laws 的幂律曲线在你眼前直播。
  4. 让它"写作":运行 python sample.py --out_dir=out-shakespeare-char,你的小 GPT 就会输出一段莎士比亚风格的角色对白——语法半通不通,但神韵十足。
做完你会:完整走过一遍"数据准备 → 训练 → 采样生成"的大模型最小闭环,理解 train.py(~300 行)和 model.py(~300 行)里到底发生了什么。下一步可以读 model.py 对照 attention 的实现,或者试试官方进阶玩法:加载 GPT-2 预训练权重做微调(config/finetune_shakespeare.py)。注意:作者已把 nanoGPT 标记为"维护放缓",同作者的全新项目 nanochat 可以花约 100 美元从零炼出一个完整的 ChatGPT 克隆,适合作为进阶下一站。
