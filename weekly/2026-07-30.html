模型精讲:注意力机制(Attention)

大模型的"理解力"到底从哪来?答案是一种会"环顾四周"的机制

核心看点:注意力机制让每个词在处理时都能"看一眼"句子里所有其他的词,并决定该重点听谁的——这是整个 Transformer 乃至今天所有大模型的地基。

它是什么

  • 注意力机制(Attention) 是 Transformer 模型的核心零件,作用是:处理一个词时,不再孤立地看它,而是让它同时参考整句话里所有其他的词。
  • 打个比方:读"The animal didn't cross the street because it was too tired"时,人脑会自动把"it"连回"animal"而不是"street"——注意力就是让模型学会这种"该关联谁"的能力。

为什么重要

  • 在 Transformer 之前,模型(RNN/LSTM)只能按顺序一个词一个词地"读",读到后面容易忘了前面,长句子尤其吃力。
  • 注意力让每个位置都能直接、并行地访问任意其他位置,既解决了"记性差",又让训练可以大规模并行——这才有了后来把模型一路做大的可能。
  • 可以说:没有注意力,就没有 GPT、Claude、Gemini。它是理解现代 AI 的第一道必过的门槛。

它是怎么工作的

  • 核心是三个向量:Query(查询)、Key(键)、Value(值)。类比查字典:Query 是"你想查什么",Key 是每个词条挂的"标签",Value 是词条里真正的内容。
  • 用当前词的 Query 去和句子里所有词的 Key 算相关度(点积后过 softmax 归一化成权重),再按权重把大家的 Value 加权求和——得到的输出就"融合"了全句相关信息。
  • 多头注意力(Multi-Head):不止算一遍,而是同时用好几组不同的 Q/K/V,从多个"平行视角"看同一句话——有的头关注语法结构,有的关注指代关系,最后把各视角拼接起来。
  • 位置编码(Positional Encoding):注意力本身不看词序(句子打乱它算出来一样),所以要额外给每个词加一个"座位号",模型才知道谁先谁后。
进阶点一(代价):注意力的计算量随句子长度呈 O(n²) 增长——序列翻倍,成本翻四倍。这正是"长上下文"又贵又难的根源,也催生了滑动窗口、稀疏注意力、线性注意力等一系列省算力的改进。
进阶点二(今天的变体):GPT 这类生成模型用的是 decoder-only + 掩码自注意力(Masked Self-Attention)——每个词只许看前面的词、看不到未来,这样才好"逐字往外蹦";推理时再用 KV Cache 把已算过的 Key/Value 缓存起来,避免重复计算、大幅提速。

动手教程:用 Ollama 在自己电脑上跑一个开源大模型

不写一行代码,10 分钟在本地拥有一个免费、离线、保护隐私的 AI 助手

你将做出:一个跑在你自己电脑上、不联网也能用的大模型,可以跟它对话、让它写文案、改代码——全程免费,数据不出你的机器。

准备:一台电脑(Mac / Windows / Linux 均可),能联网下载模型,无需任何账号,全部免费。建议 8GB 以上内存;没有 GPU 也没关系,纯 CPU 就能跑。上一期我们"训练"模型,这一期反过来——直接用别人训好的开源模型(这叫推理 / inference)。

跟着做:

  1. 安装 Ollama(约 2 分钟):

    - macOS:去官网下载 Ollama.dmg 拖进应用程序,或终端运行 curl -fsSL https://ollama.com/install.sh | sh

    - Windows:下载 OllamaSetup.exe 安装,或 PowerShell 运行 irm https://ollama.com/install.ps1 | iex

    - Linux:终端运行 curl -fsSL https://ollama.com/install.sh | sh

  2. 跑一个小模型(约 3 分钟,含下载):终端运行

    ```bash

    ollama run qwen3:0.6b

    ```

    这是阿里 Qwen3 的最小版本,仅 523MB,几乎任何电脑都跑得动。想更强就换 ollama run qwen3:4b(2.5GB,256K 超长上下文,小模型里的性价比之王)。

  3. 开始对话:命令跑起来后会直接进入交互界面,像聊天一样输入问题即可,比如让它"用三句话向小学生解释什么是黑洞"。试着追问几句,感受它"记得"上文——这背后正是上一篇讲的注意力机制在工作。
  4. 管理你的模型:新开一个终端,用 ollama list 查看已下载的模型,ollama pull <模型名> 预先下载别的模型(完整模型库见文末链接)。
做完你会:在本地拥有一个随叫随到、不花钱、数据不出门的大模型,并直观理解"推理"和上一期"训练"的区别。下一步可探索:Ollama 自带本地 API(默认 http://localhost:11434),可以把它接到你自己的小脚本/网页里当后端;或去模型库换更大的模型、试试带"思考"能力的版本。
