今日术语

  • 供应链投毒（Supply Chain Attack）：不攻击你，而是去污染你 pip install / npm install 的那个包，等你自己把后门装进生产环境。
  • .pth 文件：Python 放在 site-packages 里的一种启动钩子，解释器一起来就会执行它——所以它成了投毒者最爱的落脚点，哪怕你从没 import 过那个库。
  • 凭证轮换（Credential Rotation）：怀疑密钥泄露后，把所有 key、token、密码重新生成一遍并作废旧的，是泄露后唯一真正有效的止损动作。
  • MoE 激活参数（Active Parameters）：混合专家模型每处理一个 token 只唤醒一小撮专家，所以「24B 总参 / 2.45B 激活」意味着按 24B 的聪明程度算账、按 2.45B 的速度和显存跑。
